### 3-3. 알려진 한계 (솔직하게)

- **외부 블로커 3건**: Supabase 프로젝트 연결 불가(무료 플랜 일시정지로 **추정**, 대시보드 확인 필요), Meta 액세스 토큰·검증된 계정 없음, HTTPS 배포 도메인 미정.
- **자동 테스트 106개 중 102개 통과, 4개 실패.** 실패 4개는 이번 작업 전부터 있던 기존 문제이며, 테스트가 이전 UI(`start_project` 버튼 키, `content` 필드)를 기준으로 남아 있습니다. 현재 코드에 맞춰 정리가 필요합니다.
- 인사이트·플레이북은 **실측 데이터가 없으면 빈 화면**입니다. 데모는 빈 상태와 샘플 프로젝트 기준입니다.
- 검색(Apify)·AI 분석(Gemini)·가이드 생성은 **서버에 API 키가 있어야** 동작합니다. 회원에게는 "준비 중"으로 보이고, 키 설정은 운영자 몫입니다. 제공사별 **실제 잔여 토큰 조회는 아직 없고**, 앱이 쓴 호출 횟수만 기록합니다.
- 로그인은 새로고침하면 풀립니다(세션 유지 쿠키 미구현). 이메일 인증·비밀번호 재설정도 없습니다.
- 로그인 도입 전에 만든 데이터는 회원 화면에서 보이지 않으며, `scripts/adopt_legacy_data.py`로 계정에 복사해야 합니다.
- 프로젝트 보관·복원·영구 삭제는 구현했습니다(스튜디오 > 프로젝트 관리).

## 4. 기술 구성

## 5. 최근 개선 요약

- **화면**: 깨졌던 홈 복구, 은은한 그라데이션 배경과 반투명 카드, 웹/앱 비율 분리, 다크 모드 대비 보정, 하단 탭바 정렬.
- **계정**: 이메일 로그인·회원가입(팝업), 비회원 모드(회원 기능에서만 로그인 요구), 회원별 데이터 분리, 로그아웃 시 세션 전체 초기화(이전 사용자의 Instagram 토큰이 남던 결함 수정).
- **기능 오류 수정**: 대본 선택 예외, 접근 불가 "검토" 탭, 저장 시 제작 단계 후퇴, 플레이북 분류 오류, 동작 없던 조회 기간 선택.
- **보안**: Instagram 연결 인증 상태값을 서버 저장·일회용으로 변경(빈 값이 통과하던 결함 수정).
- **이름**: 화면에 보이는 이름을 Reels-analyzer로 통일.

## 8. 3분 시연 시나리오

0. **비회원으로 시작** — 홈과 릴스 검색은 로그인 없이 보이고, 스튜디오를 누르면 로그인 팝업이 뜨는 것을 보여준 뒤 회원가입한다.
1. **홈** — "이어서 작업하기"와 제작 5단계 현황을 보여준다.
2. **공통점 추출** — 키워드 검색(또는 링크 추가) → 릴스 선택 → 공통 패턴 → 프로젝트 생성. *(Apify·AI 키 필요, 없으면 건너뛰고 설명)*

4. **스튜디오 > 검토** — 영상 업로드 AI 검토. *(Gemini 키 필요)*
5. **인사이트·플레이북** — 실측 연동 시 보이는 화면을 설명(현재는 빈 상태이므로 "예측 vs 실측" 원칙을 말로 설명).
