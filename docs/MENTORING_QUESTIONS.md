# 멘토링 질문 (Reels-analyzer)

> 팀 **부자** · 소상공인용 AI 릴스 기획·분석 서비스
> 현황은 [`MENTORING.md`](MENTORING.md)에 있습니다. 이 문서는 **여쭤볼 질문만** 담았습니다.

## 먼저 알려드릴 현황 (30초)

- **되는 것**: 인기 릴스 검색 → 원하는 릴스만 골라 AI 분석 → 대본·촬영 계획 → 게시 정보 기록. 회원가입·로그인(비회원은 둘러보기만), 회원별 데이터 분리.
- **아직 못 한 것**: 실제 Instagram 계정 연결(Meta 심사·토큰 없음), 실측 성과 기반 학습, 실사용자 테스트, HTTPS 배포.
- **막혀 있는 것**: 클라우드 DB(무료 플랜 일시정지 복구 중), Meta 앱 심사, 배포 도메인.

## 꼭 여쭤볼 질문 (우선순위 순)

### 1. 무엇을 먼저 팔아야 하나
1. 지금은 "릴스 찾기 → 분석 → 대본 → 촬영 → 성과 학습"을 한 앱에 다 담았습니다. **처음 사장님께 하나만 보여드린다면 어느 부분**이어야 할까요?
   - *왜*: 범위가 넓어서 첫 사용자가 무엇이 핵심인지 놓칠 수 있습니다.
2. 사장님이 **실제로 돈을 낼 지점**은 어디일까요? (대본 생성 / 성과 분석 / 경쟁 추적 / 촬영 코치) 가격 감각이 있으시면 알려 주세요.
3. 타깃을 **카페처럼 한 업종으로 좁혀서** 시작하는 게 맞을까요, 업종을 넓게 두는 게 맞을까요?

### 2. 정책·법적 위험
4. **공개 릴스를 수집(Apify)해 분석**하는 것이 Instagram 약관·저작권상 서비스로 운영 가능한가요? 위험하다면 대안(공식 API, 사용자가 링크를 직접 입력)으로 가야 할까요?
5. **음원 권리**: 곡별로 상업 이용 가능 여부를 알려 주는 공개 API가 없어 "사람이 확인해야 함"으로 표시합니다. 서비스가 **어디까지 책임지고 어떻게 고지**해야 할까요?
6. **Meta(Instagram) 앱 심사**를 통과하는 현실적인 절차와 기간, 학생 팀이 준비할 서류는 무엇인가요?

### 3. AI 분석을 믿을 수 있나
7. 화면 변화량·음량 신호와 AI 해석으로 만든 **"예상 이탈 시점"을 어떻게 검증**해야 믿을 만할까요? 필요한 최소 표본 수와 평가 방법은?
8. "AI 예측은 예측이라고 표시하고, 실측만 실측으로 표시한다"는 원칙이 사용자에게 **도움이 될까요, 불신을 줄까요**?

### 4. 사용자·계정·개인정보
9. 회원이 올리는 **영상과 계정 지표**를 보관하는 서비스로서 최소한 갖춰야 할 것(동의, 보관 기간, 삭제)은 무엇인가요? 지금은 내보내기·계정 삭제·자동 정리가 있습니다.
10. 로그인은 자체 이메일 계정입니다. 초기 단계에서 **소셜 로그인(카카오·구글 등)** 으로 바꾸는 게 좋을까요, 이메일 인증·비밀번호 재설정부터 갖출까요?

### 5. 검증과 다음 단계
11. **첫 사용자 테스트**를 어떻게 설계하면 좋을까요? (몇 명, 어떤 업종, 무엇을 관찰할지)
12. 지금 단계에서 **창업 지원사업·투자 관점으로 준비해야 할 증거**(사용자 수, 인터뷰, 시연)는 무엇인가요?
13. Streamlit으로 어디까지 가고, **언제 웹 프레임워크로 옮겨야** 할까요? 무료 인프라(DB 일시정지 같은 한계)로 초기 운영이 가능한가요?
